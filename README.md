# RailEase – Railway Reservation System

RailEase is a **command-line Railway Reservation System** created as a project for the **Data Structures and Algorithms** course at **Air University**. It demonstrates real-world applications of **linked lists**, **queues**, **maps**, and **graph algorithms** to manage train schedules, reservations, and routes.

---

## 📌 Features

### 👥 User Panel
- Reserve a ticket
- View your reservations
- Cancel tickets
- Edit reservation details
- Choose a seat
- Find the shortest route between stations

### 🛠️ Admin Panel
- Login with credential verification
- Add new trains
- Depart trains
- Search trains
- View trains by route
- Display all train records

---

## 🧠 Data Structures Used

- **Linked List:** For managing train and ticket records
- **Queue:** For departure handling
- **Map + Graph Algorithm (Shortest Path):** For route optimization

---

## 💻 Technologies Used

- **Language:** C++
- **Compiler:** GCC / MinGW
- **Libraries:** STL (`map`, `queue`), `iostream`, `string`, `algorithm`
- **Platform:** Windows (Command Line Interface)
